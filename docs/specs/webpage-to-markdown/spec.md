# Webpage to Markdown Converter

## User-visible outcomes

- 사용자가 URL을 붙여넣으면 해당 웹페이지 본문이 깨끗한 Markdown으로 변환되어 화면에 나타난다.
- 변환 결과에는 페이지 제목과 저자가 헤더로 표시된다.
- 사용자는 결과를 복사하거나 .md 파일로 다운로드할 수 있다.
- 사용자는 프롬프트(프리셋 또는 직접 입력)를 선택해 본문 앞에 붙인 뒤, 클립보드에 복사되고 ChatGPT 또는 Claude가 새 탭에서 열려 붙여넣기만 하면 바로 대화를 시작할 수 있다.
- 사용자는 다크모드를 켜고 끌 수 있다.
- 사용자는 지우기 버튼으로 입력을 초기화하고 새 URL을 넣을 수 있다.

## Approved scope

- 단일 URL 입력 → Markdown 변환 (defuddle 기반) → 미리보기 (제목·저자 헤더 포함)
- 내보내기: 복사하기, .md 다운로드, ChatGPT·Claude로 열기 (클립보드 복사 + 새 탭)
- 프롬프트: "요약해줘" / "한국어로 번역해줘" / "쉽게 설명해줘" 프리셋 3종 + 직접 입력 (1회성, 저장 안 함)
- 다크모드 토글

## Observable acceptance criteria

- 유효한 URL을 넣고 변환을 실행하면, 본문 Markdown과 제목·저자 헤더가 화면에 렌더링된다.
- "복사하기"를 누르면 변환된 Markdown이 클립보드에 담긴다.
- ".md 다운로드"를 누르면 파일이 다운로드된다.
- 프롬프트를 선택(또는 직접 입력)하고 "ChatGPT로 열기"·"Claude로 열기"를 누르면, 프롬프트+본문이 클립보드에 복사되고 해당 서비스의 새 탭이 열린다.
- 프롬프트를 고르지 않고 "ChatGPT로 열기"·"Claude로 열기"를 누르면 본문만 클립보드에 복사되고 새 탭이 열린다 (프롬프트 선택은 선택적).
- 다크모드 토글을 누르면 화면 테마가 즉시 전환된다.
- 지우기 버튼을 누르면 URL 입력과 변환 결과가 초기화된다.
- defuddle이 본문을 추출하지 못하는 페이지(로그인 필요, SPA 등)에서는 변환 실패가 사용자에게 관찰 가능한 형태로 안내된다.

## Settled constraints and rationale

- 변환에는 defuddle 라이브러리를 사용한다. 실제 동작을 확인함: HTML에서 본문을 추출해 Markdown으로 변환하고, 제목·저자 등 메타데이터를 함께 제공한다. Node.js 환경에서는 별도 DOM 구현체(JSDOM/linkedom 등)가 필요하다.
- "ChatGPT·Claude로 열기"는 URL로 프롬프트를 자동 전달해 대화를 즉시 시작하는 방식이 아니라, 클립보드 복사 + 새 탭 열기 방식이다. 근거는 [llm-handoff 결정](../../decisions/llm-handoff.md) 참조 — 두 서비스 모두 새 대화를 프리필하는 공식 URL 파라미터를 현재 지원하지 않음을 확인했다.
- 프롬프트 직접 입력은 저장하지 않는 1회성이다 (PRODUCT.md의 앱 경계).
- UI는 간결하고 명확해야 한다 (PRODUCT.md의 경험 원칙).

## Assumptions

- 이번 스펙은 웹앱 형태로 제공하며 공개 API는 만들지 않는다. 사용자가 설명한 흐름이 전부 화면 상호작용이므로 별도 확인 없이 이렇게 정했다 (저비용·번복 가능한 선택).

## Off-limits areas and why

- 로그인/회원가입, 사용자별 저장소 — PRODUCT.md가 앱 전체 경계로 명시.
- 배치/대량 URL 처리 — PRODUCT.md 경계 (단일 URL 변환에 집중).
- 프롬프트 저장/커스텀 프리셋 관리 — 직접 입력은 1회성으로 한정하기로 확정됨.
- 브라우저 확장 프로그램 — PRODUCT.md 경계이며, ChatGPT·Claude 자동 프리필의 비공식 우회 수단으로도 쓰지 않는다.

## Deferred points

- defuddle이 처리하지 못하는 페이지(SPA, 로그인 필요, paywall 등)에 대한 구체적인 에러 메시지·재시도 UX는 아직 정하지 않음.
- 서비스가 API로도 제공될지는 이번 스펙에서 다루지 않음 (PRODUCT.md의 Unknown과 연결).

## Remaining risks

- defuddle의 추출 정확도가 낮은 페이지 유형이 실제 사용에서 얼마나 자주 나오는지 알 수 없어, 체감 품질에 영향을 줄 수 있음.
- 클립보드 복사 후 사용자가 실제로 붙여넣기를 하지 않으면 "바로 대화로 이어진다"는 약속된 변화가 충분히 체감되지 않을 수 있음.
